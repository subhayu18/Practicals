Natural Language Processing - Experiment 4
Word Embeddings using Word2Vec and GloVe

Aim

To generate word embeddings using Word2Vec and GloVe and explore the semantic representation of words in a numerical vector space.

Software Used

  • Python 3.10+
  • Gensim Library
  • Jupyter Notebook / Google Colab / VS Code
  • Pre-trained GloVe Word Embeddings

Theory

Word embeddings are numerical representations of words in a continuous vector space. Words with similar meanings or contextual usage are represented by vectors that are close to each other. Word2Vec learns word representations from a text corpus using contextual information and can generate embeddings using CBOW or Skip-gram approaches.

GloVe (Global Vectors for Word Representation) generates word embeddings by using global word co-occurrence statistics from a large corpus. Both Word2Vec and GloVe capture semantic relationships between words and are widely used in NLP tasks such as text classification, sentiment analysis, information retrieval, and language modeling.

Input Code

import gensim
from gensim.models import Word2Vec
import gensim.downloader as api

# Sample corpus
sentences = [
    ["natural", "language", "processing", "is", "interesting"],
    ["machine", "learning", "helps", "process", "language"],
    ["natural", "language", "is", "used", "in", "NLP"],
    ["word", "embeddings", "represent", "words", "as", "vectors"],
    ["machine", "learning", "and", "NLP", "are", "related"]
]

# Train Word2Vec model
word2vec_model = Word2Vec(
    sentences,
    vector_size=50,
    window=3,
    min_count=1,
    workers=2
)

# Display Word2Vec vector
print("Word2Vec vector for 'language':")
print(word2vec_model.wv["language"])

# Find similar words using Word2Vec
print("\nSimilar words:")
print(word2vec_model.wv.most_similar("language", topn=3))


# Load pre-trained GloVe model
glove_model = api.load("glove-wiki-gigaword-50")

# Display GloVe vector
print("\nGloVe vector for 'language':")
print(glove_model["language"])

# Find similar words using GloVe
print("\nSimilar words using GloVe:")
print(glove_model.most_similar("language", topn=3))
