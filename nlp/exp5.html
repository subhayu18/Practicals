Natural Language Processing - Experiment 5
Bigram Language Model and Add-1 Smoothing

Aim

To build a simple bigram language model, calculate bigram probabilities, observe the zero-frequency problem for unseen word pairs, and resolve it using Add-1 (Laplace) smoothing.

Software Used

  • Python 3.10+
  • NLTK Library
  • Collections Module
  • Jupyter Notebook / Google Colab / VS Code

Theory

A bigram language model estimates the probability of a word occurring given the immediately preceding word. The probability is calculated from the frequency of the word pair and the frequency of the first word.

The zero-frequency problem occurs when an unseen bigram receives a probability of zero. Add-1 (Laplace) smoothing solves this problem by adding one to every bigram count and adjusting the denominator using the vocabulary size. This ensures that unseen word pairs receive a non-zero probability.

For higher-order language models, techniques such as Kneser-Ney smoothing can provide more realistic probability estimates by using context-sensitive discounting and lower-order distributions.

Input Code

from collections import Counter

# Training data
text = "I love NLP I love Python I like AI"
words = text.lower().split()

# Create bigrams
bigrams = []

for i in range(len(words) - 1):
    bigrams.append((words[i], words[i + 1]))

# Count bigrams and unigrams
bigram_counts = Counter(bigrams)
unigram_counts = Counter(words)

# Vocabulary
vocabulary = set(words)
V = len(vocabulary)

# Without smoothing
def bigram_probability(w1, w2):
    return bigram_counts[(w1, w2)] / unigram_counts[w1]

# Add-1 / Laplace smoothing
def smoothed_bigram_probability(w1, w2):
    return (bigram_counts[(w1, w2)] + 1) / \
           (unigram_counts[w1] + V)

# Display results
print("Words:", words)
print("\nBigrams:", bigrams)
print("\nBigram Counts:", bigram_counts)
print("\nUnigram Counts:", unigram_counts)
print("\nVocabulary Size:", V)

print("\nWithout smoothing:")
print("P(love | i) =",
      round(bigram_probability("i", "love"), 4))
print("P(ai | love) =",
      round(bigram_probability("love", "ai"), 4))

print("\nWith Add-1 smoothing:")
print("P(love | i) =",
      round(smoothed_bigram_probability("i", "love"), 4))
print("P(ai | love) =",
      round(smoothed_bigram_probability("love", "ai"), 4))

Result / Conclusion

The bigram language model was successfully implemented using frequency counts from a training corpus. The zero-frequency problem was observed for unseen word pairs, and Add-1 (Laplace) smoothing successfully assigned them non-zero probabilities. The experiment demonstrates how smoothing improves language-model probability estimation.
