Named Entity Recognition using Conditional Random Fields (CRF)

Aim

To implement Named Entity Recognition (NER) using Conditional Random Fields (CRF) and identify entities such as persons, organizations, and locations from natural language text.

Software Used

  • Python 3.10+
  • sklearn-crfsuite Library

  • Jupyter Notebook / Google Colab / VS Code
  • Python re Module

Theory

Named Entity Recognition (NER) is an information extraction technique used to identify and classify named entities in text into predefined categories such as Person (PER), Organization (ORG), Location (LOC), and Miscellaneous (MISC).

Conditional Random Fields (CRF) are probabilistic sequence models that predict labels for a sequence of observations by considering both the features of individual words and the relationships between adjacent labels. In NER, CRF uses features such as capitalization, prefixes, suffixes, and surrounding words to identify named entities.

NER is widely used in information extraction, question answering, document analysis, search engines, and text mining.

Input Code

# Install before running:
# pip install sklearn-crfsuite

import nltk
import sklearn_crfsuite

# Training dataset in BIO format
train_data = [
    [
        ("Subhayu", "B-PER"),
        ("studies", "O"),
        ("at", "O"),
        ("Chandigarh", "B-LOC"),
        ("University", "I-LOC")
    ],
    [
        ("Google", "B-ORG"),
        ("is", "O"),
        ("located", "O"),
        ("in", "O"),
        ("California", "B-LOC")
    ],
    [
        ("Virat", "B-PER"),
        ("Kohli", "I-PER"),
        ("plays", "O"),
        ("cricket", "O")
    ],
    [
        ("Microsoft", "B-ORG"),
        ("develops", "O"),
        ("software", "O")
    ],
    [
        ("Delhi", "B-LOC"),
        ("is", "O"),
        ("a", "O"),
        ("large", "O"),
        ("city", "O")
    ]
]

# Extract word features
def word_features(sentence, i):

    word = sentence[i]

    features = {
        "word.lower()": word.lower(),
        "word.isupper()": word.isupper(),
        "word.istitle()": word.istitle(),
        "word.isdigit()": word.isdigit(),
        "prefix-2": word[:2],
        "suffix-3": word[-3:]
    }

    if i > 0:
        features["previous_word"] = sentence[i - 1].lower()
    else:
        features["BOS"] = True

    if i < len(sentence) - 1:
        features["next_word"] = sentence[i + 1].lower()
    else:
        features["EOS"] = True

    return features


# Prepare training features
X_train = []
y_train = []

for tagged_sentence in train_data:

    words = [word for word, tag in tagged_sentence]
    tags = [tag for word, tag in tagged_sentence]

    X_train.append([
        word_features(words, i)
        for i in range(len(words))
    ])

    y_train.append(tags)


# Initialize and train CRF
crf = sklearn_crfsuite.CRF(
    algorithm="lbfgs",
    c1=0.1,
    c2=0.1,
    max_iterations=100,
    all_possible_transitions=True
)

crf.fit(X_train, y_train)


# Test sentence
test_sentence = [
    "Rahul", "works", "at", "Google", "in", "Delhi"
]

X_test = [[
    word_features(test_sentence, i)
    for i in range(len(test_sentence))
]]

# Predict named entities
predictions = crf.predict(X_test)[0]

print("Named Entity Recognition Results:\n")

for word, tag in zip(test_sentence, predictions):
    print(word, "->", tag)
