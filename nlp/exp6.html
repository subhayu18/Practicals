Natural Language Processing - Experiment 6
POS Tagging using Hidden Markov Models (HMM)

Aim

To implement Part-of-Speech (POS) Tagging using a Hidden Markov Model (HMM) and assign grammatical tags to words in a given sentence.

Software Used

  • Python 3.x
  • NLTK Library
  • Hidden Markov Model (HMM)
  • Jupyter Notebook / Google Colab / VS Code

Theory

Part-of-Speech (POS) tagging is the process of assigning grammatical categories such as noun, verb, adjective, and adverb to words according to their context. In an HMM-based POS tagger, the words are treated as observations and their POS tags are treated as hidden states.

The HMM estimates the most probable sequence of POS tags using transition probabilities between tags and emission probabilities of words given tags. The Viterbi algorithm can then be used to determine the most likely sequence of hidden POS states for a sentence.

Input Code

import nltk
from nltk.tag import hmm
from nltk.probability import LidstoneProbDist

# Training corpus
training_data = [
    [
        ("michael", "NNP"),
        ("scott", "NNP"),
        ("is", "VBZ"),
        ("the", "DT"),
        ("manager", "NN")
    ],
    [
        ("jim", "NNP"),
        ("likes", "VBZ"),
        ("the", "DT"),
        ("office", "NN")
    ],
    [
        ("pam", "NNP"),
        ("is", "VBZ"),
        ("a", "DT"),
        ("good", "JJ"),
        ("artist", "NN")
    ],
    [
        ("dwight", "NNP"),
        ("works", "VBZ"),
        ("at", "IN"),
        ("the", "DT"),
        ("office", "NN")
    ],
    [
        ("angela", "NNP"),
        ("likes", "VBZ"),
        ("cats", "NNS")
    ]
]

# Train HMM tagger
trainer = hmm.HiddenMarkovModelTrainer()

tagger = trainer.train(
    training_data,
    estimator=lambda fd, bins:
        LidstoneProbDist(fd, 0.1, bins)
)

# Test sentence
sentence = [
    "jim", "works", "at", "the", "office"
]

# POS tagging
result = tagger.tag(sentence)

print("POS Tags:")
for word, tag in result:
    print(word, "->", tag)

Observation

Word Expected POS Category Observed Tag
Jim Proper Noun NNP
works Verb VBZ
at Preposition IN
the Determiner DT
office Noun NN

The HMM assigns POS tags based on the learned transition and emission probabilities from the training corpus.

Result / Conclusion

POS tagging was successfully implemented using a Hidden Markov Model. The model learned relationships between words and grammatical tags from the training corpus and assigned the most probable POS tags to words in the test sentence.
