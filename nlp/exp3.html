Natural Language Processing - Experiment 3
Regular Expressions for Text Processing

Aim

To use Python regular expressions for searching, extracting, cleaning, validating, and transforming structured patterns in text.

Software Used

  • Python 3.10+
  • Python re Module
  • Jupyter Notebook / Google Colab / VS Code
  • Any Python IDE

Theory

Regular Expressions (Regex) are powerful pattern-matching tools used to search, extract, validate, and manipulate text efficiently. Python provides built-in regex support through the re module. Regex is widely used in NLP preprocessing for extracting structured information such as email addresses, phone numbers, dates, hashtags, and for cleaning or normalizing text before further analysis.

Input Code

import re

text = """
Contact us at nlp.lab@example.edu or support@company.in.
Call +91-9876543210 or 81468 12735 on 06-07-2026.
Follow #NLP and #TextMining. Extra spaces should be normalized.
"""

email_pat = r"[\w.+-]+@[\w.-]+\.[A-Za-z]{2,}"
phone_pat = r"(?:\+91[-\s]?)?\d{5}[\s-]?\d{5}"
date_pat = r"\b\d{2}[-/]\d{2}[-/]\d{4}\b"
hashtag_pat = r"#\w+"

print("Emails:", re.findall(email_pat, text))
print("Phones:", re.findall(phone_pat, text))
print("Dates:", re.findall(date_pat, text))
print("Hashtags:", re.findall(hashtag_pat, text))

clean_text = re.sub(r"\s+", " ", text).strip()
masked = re.sub(email_pat, "", clean_text)

print("Clean text:", clean_text)
print("Masked text:", masked)

Observation

Operation Observation
Email Extraction Email addresses detected successfully.
Phone & Date Extraction Phone numbers and dates identified correctly.
Hashtag Detection Hashtags extracted from the text.
Text Cleaning Extra whitespace normalized using regex.
Data Masking Email addresses replaced with <EMAIL>.

Result / Conclusion

Regular expressions were successfully used to extract structured information, normalize whitespace, and mask sensitive data from text. The experiment demonstrated how regex simplifies text preprocessing and information extraction in NLP applications.
