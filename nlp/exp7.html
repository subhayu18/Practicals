Natural Language Processing - Experiment 7
Context Free Grammar and Parsing using NLTK

Aim

To define a Context Free Grammar (CFG) and parse sentences into their grammatical constituent structures using NLTK.

Software Used

  • Python 3.10+
  • NLTK (Natural Language Toolkit)
  • Jupyter Notebook / Google Colab / VS Code / PyCharm
  • Python nltk.CFG and ChartParser

Theory

A Context Free Grammar (CFG) is a collection of production rules that describes how valid grammatical structures can be generated in a language. A CFG consists of terminals, non-terminals, production rules, and a start symbol, usually S representing a complete sentence.

Parsing is the process of breaking a sentence into its grammatical constituents according to the grammar. NLTK provides a ChartParser that stores intermediate results and combines constituents to generate valid parse trees. A sentence may sometimes have more than one valid parse tree because of grammatical ambiguity.

Input Code

import nltk

# Define Context Free Grammar
grammar_text = r"""
S -> NP VP
NP -> Det N | Det Adj N | NP PP | 'I'
VP -> V NP | V NP PP | V
PP -> P NP

Det -> 'the' | 'a'
Adj -> 'small' | 'red'
N -> 'dog' | 'cat' | 'park' | 'telescope'
V -> 'saw' | 'chased' | 'ran'
P -> 'in' | 'with'
"""

# Create CFG
grammar = nltk.CFG.fromstring(grammar_text)

# Create Chart Parser
parser = nltk.ChartParser(grammar)

# Input sentence
sentence = "I saw the dog with a telescope".split()

# Generate parse trees
parses = list(parser.parse(sentence))

# Display number of parses
print("Number of parses:", len(parses))

# Display parse trees
for tree in parses:
    print(tree)
    tree.pretty_print()

Observation

Operation Observation
Grammar Definition Production rules were defined for S, NP, VP, PP, Det, N, V, and P.
Sentence Tokenization The input sentence was split into individual tokens.
CFG Creation The grammar text was converted into an NLTK CFG object.
Chart Parsing The parser generated valid grammatical structures for the sentence.
Parse Trees The resulting grammatical structures were displayed as parse trees.
Ambiguity The phrase "with a telescope" can produce multiple valid grammatical interpretations.

Result / Conclusion

A Context Free Grammar was successfully defined and used to parse an English sentence using NLTK's ChartParser. The experiment demonstrated how sentences can be divided into grammatical constituents and represented using parse trees. It also illustrated how grammatical ambiguity can result in multiple valid parse structures.
