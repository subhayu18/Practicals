Natural Language Processing - Experiment 2
Morphological Word Generation using Python

Aim

To generate valid inflected word forms from base lemmas and grammatical tags using Python.

Software Used

  • Python 3.10+
  • LemmInflect Library
  • NLTK (Optional)
  • Jupyter Notebook / Google Colab

Theory

Morphological generation is the process of converting a base word (lemma) into its correct surface form using grammatical information such as tense, number, or degree of comparison. Libraries like LemmInflect use morphological rules and lexical knowledge to generate both regular and irregular word forms. This technique is widely used in machine translation, text generation, dialogue systems, and grammar correction.

Input Code

from lemminflect import getInflection

words = [
    ("play", "VBD"),
    ("study", "VBG"),
    ("go", "VBD"),
    ("child", "NNS"),
    ("city", "NNS"),
    ("good", "JJR"),
    ("good", "JJS")
]

print("Lemma\tTag\tGenerated Form")
print("-" * 40)

for lemma, tag in words:
    form = getInflection(lemma, tag)
    print(f"{lemma}\t{tag}\t{form}")

Observation

Lemma Generated Form
play (VBD) played
study (VBG) studying
go (VBD) went
child (NNS) children
good (JJR/JJS) better, best

Result / Conclusion

Morphological word generation was successfully implemented using the LemmInflect library. The experiment generated correct inflected forms for both regular and irregular words based on grammatical tags, demonstrating the importance of morphology in Natural Language Processing applications.
