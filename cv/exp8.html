Camera Calibration

1. Aim

To implement camera calibration using a reference object of known dimensions and determine the real length of a pen from its image using pixel-to-centimeter conversion.

2. Software Used

  • Python 3.x
  • OpenCV
  • NumPy
  • Matplotlib
  • Jupyter Notebook / Google Colab

3. Theory

Camera calibration is the process of establishing a relationship between image measurements and real-world dimensions. It is commonly used in computer vision to estimate object sizes, correct lens distortion, and determine camera parameters.

In this experiment, a simple reference-based calibration technique is used. An object of known length is placed in the same plane as the pen. The number of pixels corresponding to the reference object is measured to calculate the pixel-to-centimeter ratio.

Calibration formula:

Pixels per centimeter = Reference length in pixels / Actual reference length in cm

Pen length:

Actual pen length = Pen length in pixels / Pixels per centimeter

Note: The reference object and pen should lie in the same plane and be photographed from a similar angle. This method estimates physical length but is not a substitute for full intrinsic camera calibration using a chessboard pattern.

4. Input Code

import cv2
import numpy as np
import matplotlib.pyplot as plt

# Upload or provide the image path
image_path = "pen_image.jpg"

# Read image
image = cv2.imread(image_path)

if image is None:
    raise FileNotFoundError("Image not found. Check the file path.")

# Convert BGR to RGB
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

plt.figure(figsize=(10, 6))
plt.imshow(image_rgb)
plt.title("Input Image")
plt.axis("off")
plt.show()

# Known reference length in centimeters
reference_length_cm = 10.0

# Manually measured pixel coordinates
# Replace these values according to your image
reference_start = (100, 200)
reference_end = (400, 200)

pen_start = (120, 300)
pen_end = (650, 300)

# Calculate Euclidean distance in pixels
def pixel_distance(point1, point2):
    return np.sqrt(
        (point2[0] - point1[0]) ** 2 +
        (point2[1] - point1[1]) ** 2
    )

reference_pixels = pixel_distance(
    reference_start, reference_end
)

pen_pixels = pixel_distance(
    pen_start, pen_end
)

# Calculate calibration ratio
pixels_per_cm = reference_pixels / reference_length_cm

# Estimate actual pen length
pen_length_cm = pen_pixels / pixels_per_cm

print("Reference length:", reference_length_cm, "cm")
print("Reference pixels:", round(reference_pixels, 2))
print("Pen pixels:", round(pen_pixels, 2))
print("Pixels per cm:", round(pixels_per_cm, 2))
print("Estimated pen length:", round(pen_length_cm, 2), "cm")

# Draw measurement lines
output = image_rgb.copy()

cv2.line(
    output, reference_start, reference_end,
    (0, 255, 0), 3
)

cv2.line(
    output, pen_start, pen_end,
    (255, 0, 0), 3
)

cv2.putText(
    output,
    f"Pen: {pen_length_cm:.2f} cm",
    (pen_start[0], pen_start[1] - 15),
    cv2.FONT_HERSHEY_SIMPLEX,
    0.8, (255, 0, 0), 2
)

plt.figure(figsize=(10, 6))
plt.imshow(output)
plt.title("Calibrated Measurement")
plt.axis("off")
plt.show()
