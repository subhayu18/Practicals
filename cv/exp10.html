Object Detection using YOLO

1. Aim

To study and implement the YOLO (You Only Look Once) object detection algorithm for detecting objects such as pedestrians, cars, buses, and trucks from a video.

2. Software Used

  • Python 3.x
  • OpenCV
  • Ultralytics YOLO
  • PyTorch
  • Jupyter Notebook / Google Colab

3. Theory

YOLO is a real-time object detection algorithm that identifies and localizes multiple objects in an image or video frame. Unlike traditional detection pipelines that perform separate region proposal and classification steps, YOLO processes the image in a single neural network evaluation.

The model predicts bounding boxes, class probabilities, and confidence scores. Non-Maximum Suppression (NMS) is applied to remove overlapping detections and retain the most relevant bounding boxes.

Important concepts:

  • Bounding Box: A rectangle that localizes a detected object.
  • Class Label: The category assigned to the detected object.
  • Confidence Score: Indicates the model's confidence in a detection.
  • Non-Maximum Suppression: Removes redundant overlapping boxes.
Note: This experiment uses the pretrained YOLOv8n model and the COCO dataset classes. The model weights are downloaded automatically by Ultralytics when first loaded.

4. Input Code

# Install dependencies
# pip install ultralytics opencv-python

import cv2
from ultralytics import YOLO

# Load pretrained YOLO model
model = YOLO("yolov8n.pt")

# Input video path
video_path = "input_video.mp4"

# Open video
cap = cv2.VideoCapture(video_path)

if not cap.isOpened():
    raise FileNotFoundError(
        "Unable to open video. Check the file path."
    )

# Get video properties
fps = cap.get(cv2.CAP_PROP_FPS)
width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))

print("Video FPS:", fps)
print("Video resolution:", width, "x", height)

# Output video configuration
output_path = "yolo_output.mp4"

fourcc = cv2.VideoWriter_fourcc(*"mp4v")

out = cv2.VideoWriter(
    output_path,
    fourcc,
    fps if fps > 0 else 25,
    (width, height)
)

# COCO class IDs:
# 0 = person, 2 = car, 5 = bus, 7 = truck
target_classes = [0, 2, 5, 7]

frame_count = 0

while cap.isOpened():

    ret, frame = cap.read()

    if not ret:
        break

    frame_count += 1

    # Perform object detection
    results = model(
        frame,
        conf=0.4,
        classes=target_classes,
        verbose=False
    )

    # Draw bounding boxes and labels
    annotated_frame = results[0].plot()

    # Save processed frame
    out.write(annotated_frame)

    # Display output
    cv2.imshow(
        "YOLO Object Detection",
        annotated_frame
    )

    # Press q to stop
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

# Release resources
cap.release()
out.release()
cv2.destroyAllWindows()

print("Total frames processed:", frame_count)
print("Output saved to:", output_path)
