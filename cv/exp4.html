Computer Vision - Experiment 4
Contour and Shape Detection using Python and OpenCV

Aim

To write a program to detect contours and shapes drawn within a given image using Python and OpenCV.

Software Used

  • Python 3.x
  • OpenCV (cv2)
  • NumPy
  • VS Code / PyCharm / Spyder

Theory

Contour detection is a technique used to identify the boundaries of objects in an image. OpenCV provides the cv2.findContours() function to detect contours from a binary image. The detected contours can be analyzed using their area and perimeter to identify different geometric shapes.

Shape detection can be performed by approximating the contour using cv2.approxPolyDP(). The number of vertices in the approximated contour can then be used to identify shapes such as triangles, rectangles, squares, and circles.

Input Code

import cv2
import numpy as np

# Read the input image
img = cv2.imread("shapes.jpg")

# Convert image to grayscale
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Apply thresholding
_, thresh = cv2.threshold(
    gray, 127, 255, cv2.THRESH_BINARY
)

# Find contours
contours, _ = cv2.findContours(
    thresh,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

for contour in contours:

    # Calculate contour perimeter
    perimeter = cv2.arcLength(contour, True)

    # Approximate contour
    approx = cv2.approxPolyDP(
        contour,
        0.02 * perimeter,
        True
    )

    # Get number of vertices
    vertices = len(approx)

    # Identify shape
    if vertices == 3:
        shape = "Triangle"
    elif vertices == 4:
        shape = "Rectangle / Square"
    elif vertices > 4:
        shape = "Circle"

    # Draw contour
    cv2.drawContours(
        img,
        [approx],
        -1,
        (0, 255, 0),
        3
    )

    # Display shape name
    x, y, w, h = cv2.boundingRect(approx)

    cv2.putText(
        img,
        shape,
        (x, y - 10),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.7,
        (0, 0, 255),
        2
    )

# Display result
cv2.imshow("Detected Shapes", img)

cv2.waitKey(0)
cv2.destroyAllWindows()
