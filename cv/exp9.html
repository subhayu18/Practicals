Face Detection using Haar Cascades and MediaPipe

1. Aim

To write a program to detect faces using Haar Cascades and MediaPipe in Python and OpenCV.

2. Software Used

  • Python 3.x
  • OpenCV
  • MediaPipe
  • NumPy
  • Jupyter Notebook / Google Colab

3. Theory

Face detection is a computer vision task that identifies the presence and location of human faces in an image or video. It is widely used in surveillance, attendance systems, human-computer interaction, and biometric applications.

Haar Cascade:

Haar Cascade is a machine learning-based object detection technique that uses Haar-like features, an integral image, and a cascade of classifiers. It is computationally efficient and can detect faces in real time.

MediaPipe:

MediaPipe provides machine learning solutions for real-time perception tasks. Its face detection model identifies faces and returns bounding boxes and facial keypoints.

4. Input Code

# Install required libraries if necessary
# pip install opencv-python mediapipe matplotlib

import cv2
import mediapipe as mp
import matplotlib.pyplot as plt

# Load input image
image_path = "face_image.jpg"

image = cv2.imread(image_path)

if image is None:
    raise FileNotFoundError("Image not found. Check the file path.")

image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# --------------------------------------------------
# METHOD 1: HAAR CASCADE FACE DETECTION
# --------------------------------------------------

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# Load pretrained Haar Cascade classifier
cascade_path = cv2.data.haarcascades + \
    "haarcascade_frontalface_default.xml"

face_cascade = cv2.CascadeClassifier(cascade_path)

if face_cascade.empty():
    raise RuntimeError("Unable to load Haar Cascade classifier.")

faces = face_cascade.detectMultiScale(
    gray,
    scaleFactor=1.1,
    minNeighbors=5,
    minSize=(30, 30)
)

haar_output = image_rgb.copy()

for (x, y, w, h) in faces:
    cv2.rectangle(
        haar_output,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        3
    )

    cv2.putText(
        haar_output,
        "Haar Face",
        (x, y - 10),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.7,
        (0, 255, 0),
        2
    )

print("Haar Cascade faces detected:", len(faces))

plt.figure(figsize=(10, 6))
plt.imshow(haar_output)
plt.title("Haar Cascade Face Detection")
plt.axis("off")
plt.show()

# --------------------------------------------------
# METHOD 2: MEDIAPIPE FACE DETECTION
# --------------------------------------------------

mp_face_detection = mp.solutions.face_detection
mp_drawing = mp.solutions.drawing_utils

mediapipe_output = image_rgb.copy()

with mp_face_detection.FaceDetection(
    model_selection=1,
    min_detection_confidence=0.5
) as face_detection:

    results = face_detection.process(image_rgb)

    if results.detections:
        for detection in results.detections:

            mp_drawing.draw_detection(
                mediapipe_output,
                detection
            )

        print(
            "MediaPipe faces detected:",
            len(results.detections)
        )

    else:
        print("No faces detected by MediaPipe.")

plt.figure(figsize=(10, 6))
plt.imshow(mediapipe_output)
plt.title("MediaPipe Face Detection")
plt.axis("off")
plt.show()
