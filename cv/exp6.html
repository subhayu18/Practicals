Computer Vision - Experiment 6
Pose Detection using MediaPipe and OpenCV

Aim

To write a program for pose detection using MediaPipe in Python and OpenCV.

Software Used

  • Python 3.x
  • OpenCV (cv2)
  • MediaPipe
  • NumPy
  • VS Code / PyCharm / Spyder

Theory

Pose detection is a computer vision technique used to identify and track key points of the human body from images or video. MediaPipe provides a pose detection solution that can detect body landmarks and track human movement in real time.

OpenCV is used to capture frames from the webcam, while MediaPipe processes the frames and identifies the body landmarks. The detected landmarks can be connected to form a visual representation of the human body pose, which can be used in applications such as fitness tracking, gesture analysis, sports analysis, and human-computer interaction.

Input Code

import cv2
import mediapipe as mp

# Initialize MediaPipe Pose
mp_pose = mp.solutions.pose
mp_draw = mp.solutions.drawing_utils

pose = mp_pose.Pose(
    static_image_mode=False,
    model_complexity=1,
    smooth_landmarks=True,
    min_detection_confidence=0.5,
    min_tracking_confidence=0.5
)

# Open webcam
cap = cv2.VideoCapture(0)

while True:

    success, frame = cap.read()

    if not success:
        break

    # Convert BGR to RGB
    rgb_frame = cv2.cvtColor(
        frame,
        cv2.COLOR_BGR2RGB
    )

    # Detect pose
    results = pose.process(rgb_frame)

    # Draw pose landmarks
    if results.pose_landmarks:

        mp_draw.draw_landmarks(
            frame,
            results.pose_landmarks,
            mp_pose.POSE_CONNECTIONS
        )

    # Display output
    cv2.imshow("Pose Detection", frame)

    # Press q to exit
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Observation

Operation Observation
Webcam Capture Live video frames were captured using OpenCV.
Color Conversion Frames were converted from BGR to RGB for MediaPipe processing.
Pose Detection Human body pose was detected from the live video.
Landmark Detection Body landmarks and their connections were identified and displayed.
Real-Time Tracking The detected pose landmarks followed body movements in real time.

Result / Conclusion

Pose detection was successfully implemented using MediaPipe and OpenCV. The system detected human body landmarks from the webcam feed and displayed the pose connections in real time, demonstrating the application of landmark-based human pose detection in computer vision.
