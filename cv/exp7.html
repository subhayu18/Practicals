Computer Vision - Experiment 7
Face Detection and Face Mesh using MediaPipe and OpenCV

Aim

To write a program to detect faces and face mesh using MediaPipe in Python and OpenCV.

Software Used

  • Python 3.x
  • OpenCV (cv2)
  • MediaPipe
  • NumPy
  • VS Code / PyCharm / Spyder

Theory

Face detection is a computer vision technique used to locate human faces in an image or video. MediaPipe provides solutions for detecting faces and identifying detailed facial landmarks. OpenCV can be used to capture webcam frames and display the processed results in real time.

Face Mesh extends face detection by identifying a dense set of landmarks across the face. These landmarks represent important facial regions such as the eyes, nose, lips, and face outline. The detected mesh can be visualized by drawing connections between the facial landmarks.

Input Code

import cv2
import mediapipe as mp

# Initialize MediaPipe Face Mesh
mp_face_mesh = mp.solutions.face_mesh
mp_draw = mp.solutions.drawing_utils

face_mesh = mp_face_mesh.FaceMesh(
    static_image_mode=False,
    max_num_faces=2,
    refine_landmarks=True,
    min_detection_confidence=0.5,
    min_tracking_confidence=0.5
)

# Open webcam
cap = cv2.VideoCapture(0)

while True:

    success, frame = cap.read()

    if not success:
        break

    # Convert BGR to RGB
    rgb_frame = cv2.cvtColor(
        frame,
        cv2.COLOR_BGR2RGB
    )

    # Detect face landmarks
    results = face_mesh.process(rgb_frame)

    # Draw face mesh
    if results.multi_face_landmarks:

        for face_landmarks in results.multi_face_landmarks:

            mp_draw.draw_landmarks(
                frame,
                face_landmarks,
                mp_face_mesh.FACEMESH_TESSELATION
            )

    # Display output
    cv2.imshow("Face Detection and Face Mesh", frame)

    # Press q to exit
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Observation

Operation Observation
Webcam Capture Live video frames were captured successfully using OpenCV.
Color Conversion Frames were converted from BGR to RGB for MediaPipe processing.
Face Detection Faces were detected from the live webcam feed.
Face Landmarks Facial landmarks were identified across the detected face.
Face Mesh A mesh of connected facial landmarks was displayed on the face.
Real-Time Processing The face mesh followed facial movements during live video.

Result / Conclusion

Face detection and face mesh were successfully implemented using MediaPipe and OpenCV. The system detected faces from the webcam feed and displayed connected facial landmarks in real time, demonstrating the use of facial landmark detection for computer vision applications.
