Computer Vision - Experiment 3
Warp Perspective Transformation using Python and OpenCV

Aim

To extract a sub-image from a larger image using perspective transformation (warp perspective) and display the input and output images together using Python and OpenCV.

Software Used

  • Python 3.x
  • OpenCV (cv2)
  • NumPy
  • VS Code / PyCharm / Spyder

Theory

Perspective transformation is a geometric operation used to obtain a corrected or top-down view of a selected region in an image. OpenCV provides the cv2.getPerspectiveTransform() function to compute the transformation matrix and cv2.warpPerspective() to generate the warped output. Stacking the original and transformed images allows easy visual comparison and is widely used in applications such as document scanning, image rectification, object detection, and augmented reality.

Input Code

import cv2
import numpy as np

# Read input image
img = cv2.imread("input.jpg")

# Define source points
pts1 = np.float32([[100, 100],
                   [400, 100],
                   [100, 300],
                   [400, 300]])

# Define destination points
width, height = 300, 200

pts2 = np.float32([[0, 0],
                   [width, 0],
                   [0, height],
                   [width, height]])

# Get perspective transformation matrix
matrix = cv2.getPerspectiveTransform(pts1, pts2)

# Apply warp perspective
warped = cv2.warpPerspective(img, matrix, (width, height))

# Resize warped image
warped_resized = cv2.resize(
    warped, (img.shape[1], img.shape[0])
)

# Stack images horizontally
stacked = np.hstack((img, warped_resized))

# Display result
cv2.imshow("Input and Warped Output", stacked)

cv2.waitKey(0)
cv2.destroyAllWindows()

Result / Conclusion

The selected region of the input image was successfully extracted using perspective transformation. The warped output and original image were stacked together and displayed, demonstrating the effectiveness of OpenCV's perspective transformation for image rectification and region extraction.
